## ✨ 核心特性概览

- 📱 **纯 Go 原生 SIP VoIP 电话局**：内置极轻量级 RFC 3261 SIP PBX 与 RFC 3550 RTP 媒体引擎，告别传统 Asterisk/FreePBX 数 GB 的庞大内存占用，运行内存仅数十 MB；手机与电脑秒变蜂窝电话分机，双向高清通话。
- 🤖 **双实时语音大模型 AI 代接助手**：官方原生支持**火山引擎豆包端到端实时语音大模型 (Doubao Seeduplex 3.0)** 与 **阿里百炼通义千问实时语音模型 (Qwen-Omni-Realtime)**，分机超时未接自动切入极速流式全双工 AI 代接，生成文字纪要并推送。
- 💳 **芯片级 SGP.22 eSIM 配置文件管理**：通过 3GPP AT 逻辑通道直接与 eUICC 芯片交互，在线读取 32 位 EID 与 Profile 列表，支持多运营商卡号在线一键激活切换、停用、改名与删除，无需插拔卡槽。
- ✉️ **大模型短信智能脱敏与分类中枢**：敏感信息本地正则自动掩码脱敏，杜绝隐私外泄；结合 DeepSeek / 通义千问等 LLM 自动将短信归纳为 9 大类别，支持提取验证码一键复制。
- 🔔 **全渠道即时消息通知**：支持将来电振铃、未接来电、AI 通话总结、新收短信实时推送到企业微信、飞书、钉钉自定义群机器人以及 Telegram Bot。
- ⚡ **libusb 免驱直连（完美适配群晖 DSM 7.x）**：直接通过 USB 底层总线与 4G 模组通信，彻底解决黑群晖 DSM 7.x 官方移除 `option.ko` 内核串口驱动导致模组无法识别的痛点。
- 🪶 **极简独立自包含架构**：内置纯 Go SQLite 数据库（零外部数据库依赖），静态编译单二进制文件，内置现代化响应式暗黑风 Web 界面与自动生成 HTTPS 证书。

## 📖 深度功能详解

### 1. 📱 SIP VoIP 电话分机与 RTP 媒体引擎
- **极度轻量低碳**：完全采用纯 Go 原生从零实现 RFC 3261（SIP 信令）与 RFC 3550（RTP 媒体流），摆脱传统 Asterisk、FreePBX、Kamailio 的沉重体系，仅需单个十几兆的 Docker 容器即可构建私人电话局。
- **硬件原生直通与低延迟**：默认原生匹配 G.711 u-law (`PCMU`) 与 G.711 a-law (`PCMA`) 音频编解码标准（8000Hz 单声道），直接与移远模组 UAC 音频流无缝互通，建立通话仅需毫秒级，音质清晰纯净、无任何编解码失真与杂音。
- **手机/电脑软电话多端漫游**：
  - **手机端**：完美适配 iOS / Android 平台的 **Zoiper**（免费）以及支持系统级 VoIP 锁屏强推送的 **Groundwire**。手机在后台或锁屏状态下，来电即像真实电话一样全屏振铃。
  - **电脑端**：支持 Windows **MicroSIP** 与 Mac **Telephone**，随时在工作台免提接听或使用手机卡号码外呼。
- **完整 DTMF 按键音交互**：支持 `inband`（音频带内采样）与 `rfc-2833`，无论是拨打 10086/10010 运营商客服电话查话费，还是银行信用卡按键导航，均能精准识别。
- **实时连接状态可视化**：Web 控制台实时呈现当前所有在线分机客户端的 IP 地址、User-Agent、保活倒计时（Expires）与注册状态。

### 2. 🤖 AI 智能实时语音接听助手 (双实时大模型支持)
外线打入 SIM 卡时，系统会优先振铃您的手机 SIP 分机；若您正在忙碌、拒接或超过设定的振铃时限（默认 15~30 秒），系统将平滑无缝地切入 **AI 实时语音接听助手**：

- **官方支持双顶级实时语音大模型**：
  1. **火山引擎 豆包端到端实时语音大模型 (Doubao Seeduplex 3.0)**：
     - 采用最新协议版本（`v1.2.6.1`），官方 WebSocket 直连通道（`wss://openspeech.bytedance.com`）；
     - 端到端流式全双工架构（16kHz PCM 输入 / 24kHz 高保真输出），反应极速拟真，支持自然语音打断与真实呼吸停顿；
     - 内置丰富多风格官方音色（如经典女声 `zh_female_vv_jupiter_bigtts` 等）。
  2. **阿里百炼 通义千问实时语音大模型 (Qwen-Omni-Realtime)**：
     - 基于阿里百炼全双工语音交互 API，多角色声音自由切换，理解上下文能力极强。
- **个性化助理人设与开场白定制**：
  - 可配置主人称呼（如“张先生”、“李工”）；
  - 自定义开场问候语（如：“喂，您好，请问是哪位找他？”）；
  - 自定义背景提示与交代事项（例如：“快递和外卖请告知放门口，如果是推销请礼貌拒绝”）；
  - 可选开场是否主动声明“我是 AI 电话助理”，符合合规或个人使用偏好。
- **防骚扰防爆刷安全机制**：
  - 支持单日通话次数总上限；
  - 支持单一号码每日最大呼叫限制，彻底防止恶意电话轰炸消耗大模型 Token；
  - 支持设置单次通话最大时长（超过自动礼貌挂断）。
- **实时双向转写与智能纪要推送**：
  - 对话全程自动录音与文字实时转写；
  - 挂机后，后台大模型自动提炼总结：**来电人身份**、**来电核心事由**、**紧急等级**；
  - 总结卡片毫秒级推送到您的飞书、企微、钉钉或 Telegram。

### 3. 💳 芯片级 eSIM / eUICC 配置文件在线管理 (SGP.22 eSIM Manager)
无需额外购买昂贵的专用读卡器，SimCallHub 直接让您的 4G 模组化身为强大的 LPA (Local Profile Assistant) 读写终端：

- **标准 GSMA SGP.22 规范实现**：
  - 深入利用 3GPP 标准扩展 AT 指令集（`AT+CCHO` 打开逻辑通道、`AT+CGLA` 发送 APDU 报文），直接与 eUICC 芯片上的 ISD-R（Issuer Security Domain - Root）安全域通信。
- **一键读取芯片信息与 Profile 清单**：
  - 自动识别并展示芯片独一无二的 32 位 **EID** 编码；
  - 读取已下载的运营商配置文件列表，清晰展示：**ICCID**、**运营商名称 (Provider)**、**用户别名 (Nickname)**、**激活状态 (Enabled / Disabled)**、**配置文件类型 (Class)**。
- **在线卡号热切换**：
  - 网页点击任意卡片旁的 **“启用并切换”**，即可在不插拔卡槽、不重启设备的情况下，指令模组秒级切换激活目标 eSIM，并自动重新搜网入网。
- **完整配置文件维护**：
  - 支持停用当前生效 Profile、修改自定义卡片备注名称、删除闲置或过期的废弃 Profile。
- **广泛的硬件兼容**：
  - 支持开发板板载焊接的 eUICC 芯片；
  - 支持放入卡槽的各类实体可擦写 eSIM 卡（如 **5ber**、**estk.me**、**sysmocom** 等）。

### 6. ⚡ libusb 底层免驱直连（完美适配群晖 DSM 7.x）
- **攻克黑群晖内核驱动痛点**：
  - 官方群晖 DSM 7.x 系统为了精简内核，移除了包括 `option.ko`、`ch341.ko`、`pl2303.ko` 在内的诸多 USB 串口驱动模块。在黑群晖上插上 4G 模组后，系统根本不会生成 `/dev/ttyUSB*` 节点。
- **用户态直接操控 USB 总线**：
  - SimCallHub 底层集成了 Go 原生封装的 libusb 驱动层。容器只需以 `--privileged` 运行并挂载 `/dev/bus/usb` 目录，即可直接通过 USB Vendor/Product ID 捕获并管理 EC20 / EC25 模组，与模组的各个 USB Endpoint 进行异步批量传输，**完全不依赖 host 主机内核驱动**！
- **自动断线重连**：
  - 内置模组巡检守护进程，即便发生偶发性 USB 掉电或信号重置，系统能在数秒内自动重新探测并恢复所有服务。

## 🐳 快速部署指南

### 1. Docker Compose 一键启动（推荐）

在服务器或群晖 NAS 上创建目录并新建 `docker-compose.yml`：

```yaml
services:
  simcallhub:
    image: chenpinetree/simcallhub:latest
    container_name: simcallhub
    restart: unless-stopped
    privileged: true
    devices:
      - /dev/bus/usb:/dev/bus/usb
    volumes:
      - ./data:/data
    ports:
      # Web 管理后台端口 (HTTPS)
      - "9081:9081"
      # SIP VoIP 分机信令端口 (UDP)
      - "5060:5060/udp"
      # RTP 实时通话媒体流端口范围 (UDP)
      - "20000-20100:20000-20100/udp"
    environment:
      - TZ=Asia/Shanghai
      - SIMCALLHUB_DATA=/data
      - SIM_SIP_USER=1001          # 默认 SIP 分机号
      - SIM_SIP_PASS=12345678      # 默认 SIP 分机连接密码
      - SIM_SIP_LISTEN=0.0.0.0:5060
    command: ["serve", "-listen", "0.0.0.0", "-transport", "usb"]
```

运行启动命令：
```bash
docker-compose up -d
docker logs -f simcallhub
```

> 🔐 **首次登录说明**：  
> 启动后查看容器日志，会输出首次自动生成的初始化管理员密码（如 `首次启动，已生成 Web 登录密码: xxxxxxxx`）。  
> 在浏览器访问 `https://NAS_IP:9081`（由于采用自建 TLS 证书保护，浏览器提示风险时点击“高级 → 继续前往”即可进入后台）。

## 🛠️ SIP 客户端配置指引

启动并进入 Web 控制台后，您可以在手机或电脑上配置 SIP 客户端连入网关。

### 常用推荐客户端
- **iOS / Android（手机端首选）**：免费推荐 **Zoiper**；需要系统级 VoIP 锁屏唤醒推荐付费的 **Groundwire**；
- **Windows PC**：推荐开源轻量的 **MicroSIP**；
- **Mac PC**：推荐 App Store 免费下载的 **Telephone**。

### Zoiper 快速配置与避坑要点
1. **新建账号**：`Settings` ➔ `Accounts` ➔ `+` ➔ 选 `Yes` ➔ `Manual configuration` ➔ `SIP account`。
2. **账号参数**：
   - **Domain / Server**：`你的群晖IP:5060`（若通过域名或公网访问填对应域名与端口）
   - **User name**：`1001`（对应后台分机号）
   - **Password**：`12345678`（对应后台分机密码）
   - **Caller ID**：`1001` 或群晖地址
   - **Use Outbound Proxy**：保持 **关闭**
3. **Features（按键音 DTMF）**：
   - 强烈建议切换为 **`inband`（带内音频）**，确保拨打 10086 等客服热线查话费时 4G 模组准确识别按键。
4. **Network Settings（网络关键设置）**：
   - **Enable STUN**：**务必关闭（灰色）**。在局域网内开启 STUN 会导致手机把自身内网 IP 换成公网 IP 发送，造成注册失败或通话单向无声。
   - **Enable IPv6**：建议关闭，避免手机在双栈环境下忽略局域网 IPv4。
   - **Transports**：选择 **`UDP`**。
   - **TLS Settings**：关闭。
   - *（设置后点击右上角黑色【Save】保存再返回）*
5. **Audio Codecs（音频编解码）**：
   - **仅保留开启 `u-law`（PCMU）与 `a-law`（PCMA）**，拖动到最上方，关闭其他所有旧式压缩编码（GSM、Speex 等），实现毫秒级秒通。
6. **Video Codecs（视频编解码）**：
   - 将 **`VP8`** 与 **`H.264`** **全部关闭（灰色）**。蜂窝通话是纯音频，关闭视频协商可大幅降低握手冗余并节省手机电量。
7. **注册激活**：
   - 返回账号主页，点击绿色大按钮 **【Register】**，状态显示绿色的 **`Registration status: OK`** 即代表接入成功！

## ❓ 常见问题 (FAQ)

#### Q1: 黑群晖没有 `/dev/ttyUSB*` 串口节点可以正常运行吗？
**A**: 完全可以！这正是 SimCallHub 的核心设计亮点。SimCallHub 原生内置了用户态 libusb 驱动层，指定 `-transport usb` 时，容器直接挂载宿主机的 `/dev/bus/usb` 就能接管 EC20 模组，根本不需要群晖内核存在 `option.ko` 驱动。

#### Q2: 如何在线管理我的 eSIM 卡？
**A**: 将带有 eUICC 芯片的开发板或实体可写卡（如 5ber / estk.me）插入模组卡槽，登录 Web 管理后台后进入“设备”选项卡，系统会自动读取 eUICC 芯片并列出芯片内的所有 Profile。点击任意卡片旁的“启用并切换”，模组会在数秒内完成卡号热切换并重新注网。

#### Q3: 为什么软电话接通后听不到声音（单通/无声）？
**A**: 绝大多数单向无声问题均由 NAT 或编解码协商引起：
1. **检查 STUN 设置**：在手机客户端（如 Zoiper）中，务必将 **Enable STUN 关闭**（避免局域网手机把内网 IP 换成外网 IP 导致 RTP 流投递失败）；
2. **编解码限制**：确保音频编解码器只开启 **`PCMU (u-law)`** 或 **`PCMA (a-law)`**；
3. **防火墙与端口映射**：检查群晖防火墙或 Docker 端口映射，确保 UDP `5060` 以及 UDP `20000-20100` 端口范围均已对外开放。

#### Q4: 外网或者离开家时如何使用手机接听？
**A**: 
- **方案 A（最推荐）**：使用 **Tailscale**、WireGuard 等虚拟局域网组网工具直连家庭内网，Zoiper 等软电话直接填入内网 IP 即可在全球各地安全加密接听。
- **方案 B**：在路由器上为群晖做 **UDP 5060** 和 **UDP 20000-20100** 的端口映射，配合 DDNS 域名即可实现公网直接接入。
